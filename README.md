### What I do

- 🤖 **AI agents & workflows** — tool-using agents built on Mastra / OpenAI that automate real workflows, not demos.
- 📚 **RAG assistants** — support & knowledge agents grounded in *your* content, engineered so they say "I don't know" instead of hallucinating.
- 🎨 **Generative studios** — pipelines that write, generate media, and **self-validate** their own output before it ships.

I care most about the hard part: making AI answer *accurately* and hand off to a human when it isn't sure.
